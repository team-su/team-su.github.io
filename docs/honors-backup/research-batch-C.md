### 2. SCTF（2017）— 时间/地点 UNKNOWN
检索关键词：`SCTF 2017`、`SCTF2017 题解 三叶草`、`SCTF 2017 syclover 成都信息工程大学`、`SCTF 2017 writeup`，并逐条翻查 CTFtime 2017 全年 + 2017 年 10–12 月 events API（`https://ctftime.org/api/v1/events/`），均无 "SCTF 2017" 条目。
命中的是两个不同赛事，不能混写：
- 第三届 **SSCTF** 2017（西安四叶草 / SecLover）：线上初赛 2017.05.06–05.07 —— https://www.anquanke.com/post/id/86044
- **Samsung CTF 2017**（韩国，sctf.codeground.org）—— https://github.com/d0rah/sctf2017
